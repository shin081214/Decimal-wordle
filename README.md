# Decimal Wordle

## 프로젝트 개요
"Decimal Wordle"은 기존 알파벳 워들 방식을 숫자로 치환하여 독특하게 즐길 수 있도록 한 두뇌 게임입니다.
각 영어 알파벳은 `A=01, B=02, ..., Z=26`의 숫자로 매핑되어 있으며, 숨겨진 영단어를 숫자로 추리하여 맞춰야 합니다.

---

## 🎮 신규 추가 기능: 2인 경쟁 모드 & 단축키 시스템

### 1. 시작 화면 단축키 시스템 (Quick Start Shortcuts)
게임을 시작하기 전, 첫 화면에서 키보드 숫자를 눌러 원하는 모드와 단어 길이로 즉시 진입할 수 있습니다.
* **`1`**: **경쟁 모드(2인용)** 활성화 (UI 토글도 자동으로 ON 처리됨)
* **`3`, `4`, `5`, `6`, `8`**: 해당 숫자의 글자 수 모드로 즉시 시작
* **`0`**: 10글자 이스터에그 모드로 즉시 시작
* 숫자 키를 누르지 않고 화면을 터치(클릭)하면 확률 시스템에 따라 무작위로 시작됩니다.

### 2. 2인 경쟁 모드 (Competitive Mode)
기존 협동 모드가 **무한 경쟁 모드**로 개편되었습니다. "누가 먼저 단어를 맞추는가?"를 겨루는 모드입니다.
* **선턴 무작위 배정:** 게임 시작 시 P1, P2 중 한 명이 무작위로 첫 턴을 가져가며, 이후 계속 번갈아 가며 플레이합니다 (P1 -> P2 -> P1...).
* **무제한 기회 (Infinite Scrolling Board):** 주어진 타일 줄을 모두 사용하더라도 오답일 경우 게임이 끝나지 않습니다. 오답 제출 시 맨 윗줄이 애니메이션과 함께 지워지고 맨 아랫줄에 새로운 입력 칸이 추가되어 끊임없는 대결이 가능합니다.

## 🎲 확률 시스템 및 난이도 제어 아키텍처 (Detailed Probability System)

이 게임의 코어 로직은 플레이어의 피로도를 조절하고 지속적인 흥미를 유발하기 위해 두 가지 독립적인 확률 시스템(셔플 백, 프로그레시브 잭팟)을 병렬로 운용하고 있습니다.

### 1. 셔플 백 (Shuffle Bag) 모델: 일반 스테이지 (3~7글자)
완전 무작위(RNG)로 발생할 수 있는 '불합리한 극단적 연속 출현(예: 7글자만 5번 연속 등장)'을 시스템 차원에서 차단하고, 의도된 난이도 곡선을 강제하기 위해 **셔플 백(Shuffle Bag)** 알고리즘을 사용합니다.

#### 📌 배열(Bag)의 구성 및 가중치 분포
* 주머니 안에 총 13개의 '글자 수(난이도) 구슬'을 넣고 섞습니다.
* **구성:** `[3, 4, 4, 4, 5, 5, 5, 5, 6, 6, 6, 7, 7]`
* **출현 확률 (단일 사이클 내):**
  * **3글자:** 1개 (약 7.7%) - 빠른 템포의 환기용 보너스 스테이지
  * **4글자:** 3개 (약 23.1%) - 쉬운 난이도
  * **5글자:** 4개 (약 30.8%) - **표준 난이도 (가장 높은 비중)**
  * **6글자:** 3개 (약 23.1%) - 약간 어려운 난이도
  * **7글자:** 2개 (약 15.4%) - 일반 모드 내 최고 난이도

#### 📌 동작 메커니즘
1. 게임 시작(`newGame()`) 시, 주머니(`shuffleBag`)의 맨 끝 요소 하나를 뽑아(`pop()`) 해당 게임의 단어 길이로 사용합니다.
2. 꺼낸 구슬은 버려지며, 한 번 나온 숫자는 주머니가 리셋되기 전까지 등장 확률이 점차 줄어듭니다.
3. 13판을 플레이하여 주머니가 완전히 비워지면, 즉시 초기 13개의 배열로 다시 채운 뒤 Fisher-Yates 알고리즘 방식으로 완전 셔플(Reshuffle)합니다.
4. **결과:** 아무리 운이 나빠도 7글자가 무한정 나올 수 없으며, 가장 평균적이고 편안한 4~6글자가 게임의 주축이 되도록 정밀하게 설계되었습니다.

### 2. 프로그레시브 잭팟 (Progressive Jackpot) 모델: 9글자 보스전
가장 어렵고 거대한 **9글자 보스 단어**의 출현은 독립적인 카지노형 누적 잭팟 알고리즘의 통제를 받습니다. 

#### 📌 세부 코드 로직 및 트리거 조건
* 게임 시작 시 난수 `Math.random() * 100` (0.000 ~ 99.999)을 생성합니다.
* 이 난수가 로컬 스토리지에 저장된 누적 확률값(`stats.bossProb`)보다 낮을 경우 보스전이 발동합니다.
* 보스전이 발동하지 않은 일반 게임이 끝날 때마다, **누적 확률값이 `+0.5%`씩 확정 증가**합니다.

#### 📌 확률 성장 계단 (Progression Curve)
* **1회차:** 1.0% (극악의 확률)
* **5회차 연속 미당첨:** 3.0%
* **10회차 연속 미당첨:** 5.5%
* **20회차 연속 미당첨:** 10.5%
* **50회차 연속 미당첨:** 25.5% (4판 중 1판 꼴로 급증)
* 이 모델은 플레이어에게 "판수가 누적될수록 보스전이 터질 확률이 가시적으로 높아진다"는 기대감을 주며, 언젠가는 100%에 도달해 강제 소환되는 **천장(Pity/Guarantee) 시스템**의 역할도 수행합니다.
* 잭팟이 터지면 그 즉시 출현 확률은 기본값인 **1.0%로 리셋**됩니다.

#### 📌 9글자 보스전 전용 보상 및 혜택 특례
일반 셔플 백 시스템과 달리 보스전이 발동하면 게임 내 상수와 함수가 극단적으로 변동됩니다.
1. **시청각 연출 폭주:** 타일 렌더링 지연시간 60ms → 20ms (체감 속도 3배 급증). 지진 효과(Shake) 진폭 25px → 40px로 대폭 증가. 배경이 강렬한 진홍색 틴트(`#1a0008`)로 오버레이되며 전용 일렉트릭 베이스 사운드 송출.
2. **생존 기회 보정:** 일반 글자수 공식(`6 + 글자수 - 3`)에 따르면 12턴이어야 하나, 보스 특례로 **총 13턴(`maxG = 13`)** 의 파격적인 기회를 제공.
3. **슈퍼 힌트 개방:** 중간 턴(`row == 6`) 도달 시 1글자만 알려주던 일반 힌트와 달리, **아직 맞추지 못한 글자 중 무작위 3글자를 동시에 폭격하듯 개방**하여 플레이어에게 극적인 클리어 각을 만들어줍니다.

## 기타 주요 시스템
- **입력 잠금 아키텍처 (Input Lock):** 애니메이션 재생(엔터 시) 중이거나, 추가 힌트 오버레이가 활성화된 경우 내부적으로 `isAnimating = true` 상태가 되어 모든 키보드 및 클릭 입력을 원천 차단하여 오작동 및 턴 건너뜀 버그를 완벽히 막아줍니다.
- **다이내믹 컬러 트랜지션:** 3D 회전 로직을 덜어내고, CSS Transition을 활용해 좌에서 우로 70ms 간격으로 빠르게 파도타기 하듯 색상이 스며드는 최적의 UX를 제공합니다.
- **스마트 UI 스케일링:** 9글자 18자리가 데스크톱/모바일 가리지 않고 출력되도록 보스전 시 자동으로 `.boss-board` 클래스를 붙여 타일 크기와 간격을 극도로 밀집시키며, 가로 너비 부족 시 자연스럽게 Wrap 처리됩니다.
